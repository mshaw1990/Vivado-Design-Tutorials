# 7 Series Tutorials

Tutorials that target device-specific features of AMD 7 Series FPGAs (Spartan-7, Artix-7, Kintex-7, Virtex-7 and Zynq-7000).

## [Block RAM Fundamentals](./Block_RAM_Fundamentals/)

Hands-on introduction to RAMB18E1/RAMB36E1 block RAM: instantiating the primitive vs inferring it, write modes, read latency and the output register, reset behavior, Fmax measurement, and building a deep pipelined buffer on the SSI Virtex-7 2000T.
